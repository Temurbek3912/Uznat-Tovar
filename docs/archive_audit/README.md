# Архив документов прежнего аудита полок

Здесь лежат документы про функции, которых в «Узнать товар» больше нет. Они **не удалены**, чтобы не терять историю решений,
но и **не являются инструкциями**: описанные в них команды (агент камер, ежедневный отчёт) убраны вместе с кодом.

- `CAMERAS.md` — камеры и агент камер.
- `AUTOMATION_SETUP.md` — ежедневный отчёт и Планировщик Windows.
- `AUDIT_REMOVAL_MAP.md`, `AUDIT_REMOVAL_MAP_V2.md` — карты уборки (V2 выполнена в выпуске 2026-11-06, статус — `docs/CLEANUP_STATUS.md`).

Старые данные аудита в базе PostgreSQL сохранены (таблицы не удалялись); приложение их больше не читает.
