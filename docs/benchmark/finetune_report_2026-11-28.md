Обучение — на RTX 5060 ноутбука (`ml/finetune_embedder.py --cv --final`, ключа Kaggle на компьютере нет), 27.11.2026,
папка `D:\uznat_tovar\kaggle-embedder\run1` (журналы `run1.log`, `run1b.log`; 5 проверок по ~4–7 мин + финальное 7 мин).
Рецепт: LoRA rank 16, 30 эпох, 48 товаров в пачке, lr 2e-4, температура 0.05.

Данные: 1741 фото каталога, 494 товара (`D:\uznat_tovar\kaggle-embedder\dataset`). Товары поделены на 5 частей. Модель
проверки k не видела частей k и k+1: на части k подбираются пороги «найдено», на части k+1 — замер. Снимок — фото товара,
которого модель при обучении не видела, каталог — все товары, копии снимка убраны. Это фото каталога из интернета, не снимки
магазина.

«Верный первым» — не хуже ни в одной части. Пороги здесь подобраны на одной части, поэтому неверных «найдено» в отдельной
части то больше, то меньше. Решение принималось по сумме (таблицы 1 и 3).

## 3. С правилом двойника, как в программе (`twin_threshold`)

Двойник — на векторах той же модели проверки (для дообученной — `cv_k`), проекция двойника — на всех товарах (так устроен
рабочий индекс). 1290 снимков; «не узнан» = остальное.

| Способ | «Найдено» | Из них неверно | «Похоже» (верный в пятёрке) | Не узнан | Чужой принят |
|---|---|---|---|---|---|
| **Было: SigLIP 2 + проекция, 0.83 / 0.08, двойник 0.80** | 27,6 % (356) | 2 | 654 (587) | 280 | 3,0 % |
| Дообученная, 0.78 / 0.08, двойник 0.78 | 35,0 % (451) | 0 | 333 (307) | 506 | 2,2 % |
| **Стало: дообученная + проекция, 0.84 / 0.08, двойник 0.80** | 32,9 % (424) | 0 | 679 (596) | 187 | 2,9 % |

Без проекции у дообученной модели другая шкала сходства: при прежнем `unknown_threshold` 0.70 почти 40 % снимков ушли бы в
«не из каталога». С проекцией лучше по всем столбцам: «найдено» +68, неверно 0 вместо 2, «не узнан» 187 вместо 280, чужой
принят 2,9 % вместо 3,0 %. **Включено:** дообученная + проекция, `match_threshold` 0.84, остальные пороги прежние.

## 4. Проекция для рабочего индекса

`python -m ml.train_projection --skip-check --out models/projection/siglip2-base-shop-ft.npz`. Обычная проверка внутри
`ml.train_projection` для дообученной модели нечестная: финальная модель видела все товары каталога (там 83 % «первым» без
проекции). Поэтому флаг `--skip-check` пишет файл без неё. Честная проверка — таблицы выше.
