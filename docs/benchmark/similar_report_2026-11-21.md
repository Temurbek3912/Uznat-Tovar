# Похожие товары и объёмы: замер и улучшения 2026-11-21

Задача владельца: «улучшить точность любыми способами — чтобы не путал похожие товары и различал объём (0,5 и 1,5 л),
ничего не сломав и не навредив ноуту».

## Коротко, для владельца

1. **Сколько верно сейчас.** На 1290 честных снимках каталога (500 товаров, без копий одного снимка) верный товар первым —
   **62,8 %**, в первой пятёрке — 76,1 %; на лицевых снимках — 66,5 % / 79,2 %. У товаров одной марки — 57 %, у товаров,
   у которых в базе есть другой объём, — 59 %. Путаница «тот же товар, другой объём» — 10 ошибок из 1290; «та же марка,
   другой товар» (вкус, вид) — 95; остальное (375) — снимок вообще не похож на фото того же товара в каталоге (обратная
   сторона, состав, штрихкод).
2. **Главная беда была не в первом месте, а в уверенности.** Из ответов «найдено» (уверенно) **каждый пятый был ошибкой**
   (93 из 455). Теперь, когда второй товар почти так же похож (ближе 0,04), программа не говорит «найдено», а показывает
   «похоже» с вариантами; порог «найдено» — 0,86 вместо 0,88. Итог: уверенных ответов почти столько же (**33 % против 35 %**),
   а уверенных ошибок **втрое меньше (30 против 93)**; на лицевых снимках уверенных ответов больше (97 против 83) при тех же
   5 ошибках; товар, которого нет в базе, «узнаётся» реже (**3,4 % против 8,2 %**).
3. **Объём.** Модель «зрение + текст» почти никогда не пишет объём в названии (6 снимков из 365) — прежняя проверка объёма
   по этикетке почти не работала. Теперь, если рядом другой объём того же товара, программа задаёт модели два коротких
   вопроса («какой объём напечатан» и «какой из вариантов») и верит, только если ответы совпали: **верно 61 из 62**. Не видно
   объёма — честно «уточните объём» со всеми объёмами. Товар без объёма в названии («Pepsi») и тот же с объёмом
   («Pepsi 1,5 л») теперь тоже считаются разными объёмами — раньше программа уверенно выбирала один из них наугад.
4. **Что не помогло** (проверено и не взято): подготовка кадра (дополнение до квадрата, обрезка по центру, усреднение
   нескольких вариантов) — хуже на 1–5 пунктов; другое сложение оценок нескольких фото товара и «расширение запроса» — хуже;
   сверка кадра с текстом названия той же моделью SigLIP 2 — +0,4…1 пункт, в пределах случайности; выбор между похожими
   товарами по надписи, прочитанной моделью, — исправил 13, испортил 7 (+0,5 пункта, случайность). Модель поиска по виду на
   этих фото выжата; дальше точность первого места поднимают **свои фото товаров** (лицевая сторона, как снимает
   покупатель), а не хитрости.
5. **Где ещё может ошибаться.** Товары одной марки с похожей упаковкой (вкусы чипсов, сметана 15 % / 20 %), если на кадре
   не видна надпись; объём, если он не виден на снимке (тогда — «уточните»); товары, у которых в каталоге нет лицевого фото.
   Всё измерено на фото каталога из интернета, **не на снимках магазина** — пороги стоит проверить на своих фото
   (`docs/benchmark_photo_guide.md`, `ml/evaluate_matching.py`).

## 1. Набор и как повторить

    .venv/Scripts/python.exe -m ml.benchmark_similar --out D:/uznat_tovar/accuracy-2026-11-21/after

`ml/benchmark_similar.py` только читает рабочий индекс (`models/index`, векторы SigLIP 2 base — без видеокарты) и базу.
«Оставить одно»: каждое фото — снимок, остальные — каталог; фото того же товара со сходством > 0,93 (копии) убраны, как в
`ml/benchmark_no_copies.py`; считаются снимки, у товара которых осталось другое фото: **1290 из 1741** векторов
(494 товара в распознавании: 4 в архиве, 53 фото выведены из эталонов). «Лицевые» — фото, загруженные как `front`
(245 снимков). «Одна марка» — у марки ≥ 2 товаров (582). «Есть другой объём» — то же название и марка, другой объём или
объём не указан (64 снимка, 17 пар — список в отчёте инструмента). «Товар не из базы» — тот же снимок, из каталога убраны
все фото его товара. Решение «найдено / похоже / не знаю» — `decide_match`, как в программе.

## 2. До и после (один и тот же набор)

| | Было (0,88, запас 0) | Стало (0,86, запас 0,04) |
|---|---|---|
| Верный товар первым / в пятёрке | 62,8 % / 76,1 % | без изменений (порядок кандидатов тот же) |
| «Найдено» (уверенно) | 35,3 % (455) | 33,3 % (429) |
| Из них неверно | **93 (20,4 %)** | **30 (7,0 %)** |
| Лицевые: «найдено» / неверно | 83 / 5 | 97 / 5 |
| Товар не из базы «найден» | 8,2 % | 3,4 % |
| Кадров, где спрашивается модель «зрение + текст» | 78,2 % | 73,8 % |

Сетка «порог × запас» — в отчёте инструмента (`report.md`, `grid.csv`). Выбрана точка, где уверенных ответов почти столько
же, а ошибок и ложных «нашёл» меньше по всем трём строкам; 0,88 с запасом 0,04 даёт ещё меньше ошибок (20), но уверенных
ответов меньше (26,5 %).

Проверка объёма в программе (с запасом, без модели этикеток): уверенных ответов «другим объёмом» 4 -> 3, «уточните объём»
19 -> 36 снимков (сюда же перешли 8 верных уверенных ответов — у пары «с объёмом / без объёма» выбор теперь за человеком).
