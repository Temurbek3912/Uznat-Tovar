## Правила

- Вывод с кириллицей не резать по байтам (`cut`, `head -c`): инструмент вывода ломается на оборванных символах. Для обрезки использовать Python.
- Ничего рабочего не удалять, **кроме аудита полок** (разрешено). Не менять существующие таблицы БД без резервной копии; новые данные — новыми таблицами.
- Никаких выдуманных результатов распознавания или перевода. Не писать «исправлено» без проверки: честно разделяй «проверено у меня» и «проверить на моём компьютере».
- Ключи и пароли — только в переменных окружения. Платные и облачные сервисы — только после моего согласия (облачные я уже отклонил).
- Если в песочнице нет сети или библиотек — так и скажи; проверяй статически (`ast`, `py_compile`, `tools/import_graph_check.py`), а полные тесты проси запустить меня.
- Лицензии моделей проверять до выбора для продукта (проект пойдёт в магазины, то есть возможно коммерческое использование).
