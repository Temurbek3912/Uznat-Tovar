# Ежедневный отчёт и автоматизация

## Что делает ежедневный отчёт
За **календарные сутки в часовом поясе `Asia/Tashkent`** (UTC+5; меняется переменной `APP_TIMEZONE` в `.env`) по каждому магазину: сколько снимков, сколько **обработано**, сколько **с ошибкой обработки**,
сколько **не обработано** (в очереди/обработке), среднее OSA и Compliance, покрытие полок, перечень проблемных снимков и событий камер за сутки. Файлы — CSV, XLSX, PDF.

Правила честности (проверены тестами):
- **«Снимков не было» ≠ «OSA 0%»**: день без снимков так и пишется, средние не считаются.
- Снимки `failed` и необработанные (`queued`/`processing`) **успехом не считаются**, в средние не входят и перечислены отдельно.
- Если у полки нет планограммы, OSA/Compliance, посчитанные конвейером, бессмысленны (OSA 100%, соответствие 0%) — загрузите планограммы.
- «Вчера» — по местному календарю: в 01:00 по Ташкенту это ещё 20:00 UTC предыдущих суток.

## Вручную
В админ-панели: «Обзор» → блок «Ежедневный отчёт» → дата (пусто = вчера) → «Показать» / CSV / XLSX / PDF. Или командой (**только чтение базы**):

```powershell
docker compose exec -T api python -m scripts.daily_report                  # за вчера, все магазины -> data\reports\daily\ГГГГ-ММ-ДД\
docker compose exec -T api python -m scripts.daily_report --date 2026-10-09 --formats csv,xlsx
docker compose exec -T api python -m scripts.daily_report --store-id <ИД магазина>
```
Файлы лежат на вашем диске в `data\reports\daily\<дата>\` (папка проекта примонтирована в контейнер). Повторный запуск за ту же дату перезаписывает файлы этой даты и ничего больше не трогает.
Код выхода 0 — отчёт сформирован; 1 — ошибка (база недоступна, неверная дата).

## Автоматически: Планировщик заданий Windows
В проекте есть `scripts\run_daily_report.bat`: переходит в папку проекта, запускает отчёт за вчера и дописывает вывод в `logs\daily_report.log`. Создайте задачу (PowerShell от вашего пользователя):

```powershell
schtasks /Create /SC DAILY /ST 06:00 /TN "ShelfAudit-DailyReport" /TR "D:\retail-shelf-audit\scripts\run_daily_report.bat"
schtasks /Run /TN "ShelfAudit-DailyReport"          # проверить сразу; результат — в logs\daily_report.log
```
Время `06:00` — по часам Windows (границы суток отчёта от них **не зависят**: они берутся из `APP_TIMEZONE`). В «Планировщике заданий» → свойства задачи → «Параметры» включите
**«Запускать задачу как можно скорее после пропуска запланированного запуска»** — иначе выключенный в 06:00 ноутбук пропустит отчёт.
Требуется запущенный Docker Desktop и контейнеры (`docker compose up -d`; контейнеры стартуют сами вместе с Docker Desktop, если он запускается при входе в систему).
*Эти команды составлены по документации Windows и в этой среде не выполнялись.*

## Чего нет
Отправки отчёта по почте/в Telegram **нет** — отчёт сохраняется файлами. Отчёты хранятся без срока (как и снимки) — следите за местом на диске (админ-панель → «Система»).
Бэкап базы данных — отдельная команда: `python scripts\backup_db.py` (проверяемая копия; подробности в `docs/DOCKER.md`).
