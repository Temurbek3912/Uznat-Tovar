Товаров в каталоге (эталоны): 40; товаров «не из каталога»: 12. Фото: эталоны 200, подбор порогов 260, контроль 260.
Съёмка эталонов никогда не попадает в запросы; цифры ниже — только на **контрольных** съёмках.
Интервалы — 95 %, bootstrap по товарам (1000 повторов); при нуле ошибок верхняя граница — точное «правило трёх».
