# Облегчённый режим и требования к компьютеру

Коротко для владельца. Цифры — замеры 2026-11-14 на компьютере разработки; подробно — `docs/architecture/11_PERFORMANCE.md`, §10.
**На настоящем слабом ноутбуке программа ещё не проверялась.** Там всё будет медленнее, насколько — пока неизвестно.

## Два режима

| | **Полный** — `start_demo.bat` | **Облегчённый** — `start_lite.bat` |
|---|---|---|
| Что нужно | Docker Desktop | только сама программа |
| Память программы | около 3,6 ГБ (из них Docker — 2,2 ГБ) | около **1,2 ГБ** |
| Запуск | около 20 с (Docker, база, программа) | около 10 с |
| Товар из базы (штрихкод или по виду) | да, около 0,3 с | да, около 0,3 с (на процессоре, без видеокарты) |
| Товар вне базы по штрихкоду (открытые базы в интернете) | да | да |
| Товар вне базы по фото, без штрихкода | да, около 1 с — если есть видеокарта NVIDIA | только с видеокартой на 6 ГБ и ОЗУ от 12 ГБ; иначе — только вид товара («Это напиток», «Обувь») малой моделью, 0,1 с на процессоре |
| Вид товара вне базы («Это напиток») | да (обе модели должны согласиться) | да, малая модель SigLIP 2 (+0,4 ГБ памяти; скачивается один раз при первом запуске с интернетом) |
| База | PostgreSQL | файл `data/lite/shop.db` (свои товары и пользователи) |

Если на компьютере нет Docker, `start_demo.bat` сам запустит облегчённый режим.

**Важно: у режимов разные базы.** Чтобы в облегчённом режиме были те же товары, один раз выполните (при выключенной программе,
Docker должен работать):

    .venv\Scripts\python.exe -m scripts.lite_copy

Повторный перенос: добавьте `--replace` — прежние данные облегчённого режима не удаляются, а переносятся в папку
`data\lite.bak-<дата>`.

## Требования к компьютеру

| | **Минимальные** (облегчённый режим) | **Рекомендуемые** (полный режим со всем) |
|---|---|---|
| Система | Windows 10 или 11, 64 бит | Windows 11, 64 бит |
| Процессор | 4 ядра (с AVX2 — почти все с 2015 года) | 6–8 ядер и больше |
| Оперативная память | 8 ГБ | 16 ГБ и больше |
| Видеокарта | не нужна | NVIDIA с 6–8 ГБ видеопамяти (для названий товаров вне базы по фото) |
| Диск | SSD, 10 ГБ свободно + место под фото товаров | SSD, 50 ГБ свободно и больше |
| Интернет | нужен только для штрихкодов товаров вне базы | то же |

Почему так:
- распознавание товара по виду на процессоре почти так же быстро, как на видеокарте (0,13 с против 0,015 с на снимок; весь ответ —
  около 0,3 с в обоих случаях), а точность та же — проверено: результаты совпадают полностью;
- модель «зрение + текст» (называет товар вне базы по фото) без видеокарты отвечает 10–22 с даже на сильном процессоре и занимает
  5–8 ГБ памяти — на слабом ноутбуке это дольше предела ожидания, поэтому там она выключается сама.

## Что ещё не проверено

- настоящий слабый ноутбук (8 ГБ, 4 ядра, без видеокарты): нужен замер «Узнать товар» и запуска на нём;
- облегчённый режим с телефона через Wi-Fi (на этом компьютере проверено через браузер и программой замера);
- добавление товара кнопками страницы «Товары» в облегчённом режиме (проверено тестами, не вживую).

Ручные переключатели: `start_lite.bat --cpu` — только процессор, даже если видеокарта есть; `--vision on` / `--vision off` —
включить или выключить модель «зрение + текст» вручную.
