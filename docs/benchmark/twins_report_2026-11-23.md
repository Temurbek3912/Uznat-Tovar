видит: второй по счёту — далеко.

## Правило двойника

Даже при высоком счёте ответ — «похоже, выберите», если среди кандидатов есть товар, чьи фото **в каталоге** почти такие же, как у
лучшего (наибольшее сходство их эталонных фото ≥ `twin_threshold`). Человек видит оба варианта и выбирает. Считается на лету по
векторам индекса (`ProductMatcher.twin_similarity`), выведенные из эталонов фото не участвуют; база и индекс не меняются.

| Способ | «Найдено» | Из них неверно | «Похоже» (верный в пятёрке) | Чужой товар принят |
|---|---|---|---|---|
| Сейчас (0,83 / запас 0,08) | 32,0 % (413) | **23** | 597 (534) | 3,1 % |
| Двойник 0,75 | 23,5 % (303) | 2 | 707 (640) | 2,6 % |
| Двойник 0,78 | 26,6 % (343) | 2 | 667 (600) | 3,0 % |
| **Двойник 0,80 — включено** | **27,6 % (356)** | **2** | 654 (587) | 3,0 % |
| Двойник 0,82 | 29,8 % (384) | 9 | 626 (561) | 3,1 % |
| Двойник 0,85 | 30,2 % (389) | 14 | 621 (556) | 3,1 % |

Цена: 57 ответов «найдено» стали «похоже» (из них 21 были ошибками). «Верный первым» не меняется (70,1 %): правило меняет только
«уверенно / похоже». Оставшиеся 2 ошибки — O'Zera (на честной проверке сходство пары 0,79; в рабочем индексе 0,835 — правило их
поймает). На рабочем индексе проверены пары из таблицы: Био-С 0,824, «Антарктик-криль» 0,814, «Провансаль» 0,855, Lay's 0,806,
Активиа 0,868 — все ≥ 0,80.

## Строгий режим (выключен; включает владелец)

`models.matcher.strict: true` — «найдено» только при счёте ≥ 0,88 (вместе с правилом двойника):

| Режим | «Найдено» | Из них неверно | Чужой товар принят |
|---|---|---|---|
| Обычный (двойник 0,80) | 27,6 % | 2 | 3,0 % |
| Строгий 0,86 | 20,8 % | 2 | 1,4 % |
| **Строгий 0,88** | 15,1 % | **0** | **0,7 %** |
| Строгий 0,90 | 9,3 % | 0 | 0,1 % |

«Чужой товар принят» — товара нет в каталоге (новый вкус ещё не добавлен), а программа уверенно назвала соседний. Правило двойника
тут не помогает (двойника в каталоге нет) — помогает только строгий порог.

ImageNet: они различают «бутылка / пачка», а не «Fanta / Pepsi одной формы».

## Объём по пропорциям рамки (опыт владельца)

Рамку товара обвела модель зрения (Qwen3.5-35B, только фото, где товар виден целиком), пропорция — высота / ширина рамки:
Coca-Cola 1 л — 3,43 и 3,31, Coca-Cola 1,5 л — 3,33, вода Tassay 1,5 л — 3,0–3,7; кетчуп Heinz 350 г — 1,6, 320 г — 1,69. Бутылки
одной линейки разных объёмов почти одной формы: разброс между фото одного товара больше разницы между объёмами. Где форма разная
(кетчуп 1000 г — бутылка, 2,7), товары и так различает поиск по виду. Фото каталога — крупные планы: товар целиком виден лишь на
~10 из 39 фото товаров с соседним объёмом. Не внедряем; объём по-прежнему читается с этикетки (`naming.size_question`).

Опыты — `D:\uznat_tovar\accuracy-2026-11-23` (скрипты e0…e6, векторы `vec224.npy` / `vec384.npy`).

Вернуть как было: `twin_threshold: 0` в `configs/config.yaml` (индекс пересобирать не нужно).
