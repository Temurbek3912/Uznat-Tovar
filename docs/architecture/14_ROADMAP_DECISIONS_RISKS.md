## 2. Журнал решений

### 2.1. Утверждено владельцем (задание 2026-11-06)

1. Строго один магазин, один владелец, один компьютер или сервер, один каталог, один постоянный QR. `Store`, пользователи, роли и
   привязки сохраняются. `store_id` не добавляется механически.
2. Local-first: без облака, без обязательного интернета, без отправки фото покупателей третьим лицам.
3. Покупатели анонимны; историю можно хранить 30–90 дней без лишних персональных данных.
4. Интерфейс: три языка и четыре языковых варианта интерфейса — русский; английский; узбекский (латиница); узбекский (кириллица).
5. Каталог до 10 000 SKU; `Product` = SKU, без переименования; импорт и экспорт Excel/CSV; кассы — позже; семейства — не сейчас.
6. Backend не переписывается; PostgreSQL остаётся основной; Celery и Redis — для Docker (dev/server).
7. Для Desktop — очередь без обязательного Redis, после анализа надёжности.
8. OCR обязателен; Tesseract остаётся до испытаний.
9. Модели, веса, индексы и ML-конфигурация не меняются в рамках этой задачи; benchmark до крупных изменений.
10. Для первой локальной версии допустим `<input capture>` без HTTPS.
11. Резервные копии — приоритет, с проверкой реального восстановления.
12. Облако и синхронизация — не сейчас.
